## Overview

MySQLQuery is a tool that connects to MySQL database to execute SQL queries。


## Configuration
 
1. Configure startup parameters in the function library
In the MySQL function panel of the function library, click … > Start the parameters, fill in the database connection parameters, and enable the function。   
![Startup parameters](/admin/tool/img/MySQL_setting.jpg)
2. Use in the application
In the Advanced Orchestration app, click Add Component->function library->MySQLQuery, set query content。
![Used in the application](/admin/tool/img/MySQL_app_used.jpg)
