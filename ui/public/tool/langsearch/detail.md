## Overview

LangSearch It is a freeWeb Search APIandRerank APIservice, supporting news, images, videos and other content. It combines keywords and vectors for hybrid search to improve accuracy。


## Configuration

1. getAPI Key 
In[LangSearch](https://langsearch.com/overview) Apply on API Keys。
![API Key](/admin/tool/img/langsearch_APIKey.jpg)
2. Configure in function library
In the LangSearch function panel of the function library, click … > Launch parameters, fill in API key and enable the function。   
![Startup parameters](/admin/tool/img/langsearch_setting.jpg)
3. Use in the application
In the Advanced Orchestration app, click Add Component->function library->LangSearch，Set usage parameters。
![Used in the application](/admin/tool/img/langsearch_app_used.jpg)
