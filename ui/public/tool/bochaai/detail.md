## Overview

Bocha tool is a tool that supports natural language search Web Search API，Search for high-quality world knowledge from nearly 10 billion web pages and ecological content sources, including news, pictures, videos, encyclopedias, wine, academics, etc.。


## Configuration

1. getAPI Key 
In [Bocha Open Platform](https://open.bochaai.com/overview) Apply on API Keys。
![API Key](/admin/tool/img/bocha_APIKey.jpg)
2. Configure in function library
In the Bocha function panel of the function library, click … > Launch parameters, fill in API key and enable the function。   
![Startup parameters](/admin/tool/img/bocha_setting.jpg)
3. Use in the application
In the Advanced Orchestration app, click Add Component->function library->Bocha, set usage parameters。
![Used in the application](/admin/tool/img/bocha_app_used.jpg)
